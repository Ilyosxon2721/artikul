# Artikul — Support FAQ (internal)

Use this when answering users in Telegram-чате @artikul_uz, by email,
or in the contact form.

## Account

**"Не приходит SMS-код."**
Подождите 60 секунд, проверьте формат номера (+998…). Eskiz иногда
запаздывает в роуминге. Альтернатива — регистрация по email.

**"Можно ли зарегистрироваться без телефона?"**
Да. На странице регистрации выберите вкладку «По email».

**"Я заблокирован."**
Напишите на support@artikul.uz с кратким описанием ситуации. Снимаем
блокировки только после ручного разбора.

## Tasks

**"Сколько откликов можно получить на одну задачу?"**
До 50. После — приём откликов закрывается, можно перепубликовать задачу.

**"Можно ли редактировать задачу после публикации?"**
Только если в статусе Draft или Published. После принятия отклика —
изменения через чат с исполнителем.

## Proposals

**"Сколько откликов в день можно отправить?"**
10 для неверифицированных исполнителей, без лимита для верифицированных.

**"Я отправил отклик, но он не виден заказчику."**
Заказчик видит отклики после открытия таб «Отклики» в карточке задачи.
Если статус «отозван» — значит вы сами отозвали.

## Contracts

**"Когда можно открыть спор?"**
Когда контракт в статусе in_progress / submitted / in_review / revision.
После завершения сделки спор не открыть — обращайтесь напрямую в
support@artikul.uz.

**"Сколько раз можно отправить на доработку?"**
По умолчанию 3 итерации.

## Chat

**"Почему мой телефон в чате заменён на •••?"**
Контактная информация (телефоны, email, ссылки на мессенджеры) блокируется
до момента принятия отклика. После старта сделки — без ограничений.

## Verification

**"Долго ли проверяют заявку на верификацию?"**
1–3 рабочих дня. Уведомление придёт по email и (если привязан) в Telegram.

**"Зачем нужны скриншоты кабинета маркетплейса?"**
Это подтверждение реального опыта продаж. Финансовые данные можно скрывать
маркером — нам нужны заказы, отзывы, конверсия.

## Telegram

**"Как привязать Telegram-бот?"**
В личном кабинете → /profile/notifications → «Сгенерировать код» →
«Открыть бота» → отправьте код в чат бота.

## Payment (MVP)

**"Как Artikul удерживает деньги?"**
В MVP-версии — никак. Оплата напрямую между сторонами. В фазе 2 будет
эскроу через банк-партнёра.
